CIVOCI AI — Step 4

This version connects the dashboard to a backend that relays Binance's public BTCUSDT 1-minute kline stream.
It does NOT connect to Quotex and does NOT place trades.

Run:
1. npm install
2. npm start
3. Open http://localhost:3000

Deploy the whole folder to a Node hosting service such as Render. Do not deploy only index.html because the WebSocket backend is required.

The signal is an experimental trend/momentum indicator and is not guaranteed.
